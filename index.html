How findings surface

From observation to issue

  1. Observe → run a test and log the outcome
  2. Reproduce → confirm it happens again
  3. Triangulate → narrow version, platform, and trigger
  4. Document → write up repro steps and evidence
  5. Link → attach the GitHub issue
  6. Report → surface the finding to MonkeyCode
